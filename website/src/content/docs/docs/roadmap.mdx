## In progress — v0.13.0

- **Per-display parking and workspace routing.** Every display gets an
  active workspace, monitor pins are honored, fallback workspaces use
  display names, and switching to a workspace already on another display
  focuses that display instead of swapping layouts.
- **`tili query` and `tili subscribe --json`.** JSON snapshots and
  line-delimited events for status bars and scripts.
- **Window metadata and rules.** `bundle_id`, `workspace`, `focused`,
  `role`, `subrole`; copy-rule CLI/menu bar; `role`/`subrole` matchers.
- **Native-tab guard.** App-owned tabs stay inside the app: opening,
  closing, or switching tabs must not create placements or relayout.
- **Floating toggle.** `toggle-floating` command and default hotkey.
- **Responsiveness.** Configurable AX timeout, 500ms default.

## Shipped

- **v0.12.0** — session state and recovery.
- Earlier releases — see the [CHANGELOG](https://github.com/itsdezen/tili/blob/main/CHANGELOG.md).

## Planned

- **Tabbed/stacked containers.** A third container kind; design spike first.
- **Full native-tab support.** Only if the guard proves insufficient;
  depends on reliable AX tab semantics.
- **Sticky windows.** Stay visible across workspace switches.

## Design principles

- **Public API only.** One documented private call; no SIP disable, ever.
- **Event-driven, not polling.**
- **The animation seam stays a seam.**
